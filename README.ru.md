# Генератор FHIR CodeSystem для LOINC

[English version](README.md)

Превращает официальный выпуск LOINC в один полный FHIR R4 `CodeSystem` для `http://loinc.org`. Кроме терминов LOINC в него входят все части (LP), списки ответов (LL) и ответы (LA), поэтому FHIR-валидаторы и сборки IG находят все эти коды без доступа к серверу терминологии.

В репозитории только генератор, данных LOINC здесь нет: выпуск вы скачиваете сами, бесплатно, с loinc.org.

## Что нужно

- Python 3.8 или новее. Устанавливать пакеты не нужно.
- Бесплатная учётная запись на loinc.org для скачивания выпуска.

## Как сгенерировать CodeSystem

1. Войдите на https://loinc.org/downloads/ и скачайте **LOINC Complete** (`Loinc_<версия>.zip`, около 90 МБ). Сверьте контрольную сумму MD5 с указанной на странице.
2. Скачайте предыдущий выпуск `Loinc_<предыдущая версия>.zip` из архива https://loinc.org/archive (см. [зачем](#зачем-нужен-предыдущий-выпуск)).
3. Положите оба архива рядом с `generate.py` и выполните:

   ```bash
   python3 generate.py Loinc_2.83.zip --previous Loinc_2.82.zip
   ```

   Скрипт за ~10 секунд создаёт `CodeSystem-loinc-2.83-parts-answers.json` (около 160 МБ) и выводит число кодов каждого вида. Версия берётся из имени архива; если вы его переименовали, укажите `--version`, а другое имя выходного файла задаётся через `-o`. Вместо архива можно указать распакованную папку выпуска.

Вместо архива предыдущего выпуска в `--previous` можно передать CodeSystem, ранее созданный этим скриптом: так каждый выпуск строится на предыдущем.

## Зачем нужен предыдущий выпуск

LOINC никогда не удаляет коды и не использует их повторно, но в файлах каждого выпуска часть кодов отсутствует. В 2.83 из `Part.csv` пропали 228 выведенных из употребления частей LP, а из `AnswerList.csv` — 2 ответа LA, которые больше не входят ни в один список. Данные, уже закодированные ими, остаются корректными, поэтому `--previous` сохраняет все коды предыдущего выпуска, которых нет в новом, и помечает их `inactive`. `STATUS` для них берётся из `ChangeSnapshot/PartChangeSnapshot.csv` выпуска, а если кода там нет, ставится `INACTIVE`.

## Состав и лицензии

Подробная таблица свойств — в [английском README](README.md#whats-in-the-codesystem). Для LOINC 2.83 результат содержит 112 405 терминов, 75 165 частей LP, 5 009 списков LL и 22 363 ответа LA.
